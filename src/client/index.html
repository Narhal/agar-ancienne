    Touches

    Manette

    • Stick gauche : direction (le centre immobilise)
    • A / Croix : split · X / Carré : nourrir
    • B / Rond ou Y / Triangle : rappel
    • Start / Options : classement complet
    • Menu : croix directionnelle + A pour valider

    Comment jouer

    • Déplacez la souris (ou le stick) pour diriger votre cellule.
    • Mangez la nourriture et les joueurs plus petits pour grossir.
    • Split pour attraper, nourrir pour pousser une masse, rappel pour vous refondre.
    • Le score de partie combine les snapshots réguliers, la masse finale et les kills.
